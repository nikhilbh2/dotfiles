# Resume check

- Project record and observation date:
- Goal / acceptance criteria / constraints understood:
- Repository / worktree / actual branch / HEAD:
- Dirty or untracked work:
- Live task / PR / CI evidence:
- Required artifacts present and durable:
- Active writer and ownership:
- Differences from the handoff:
- Unverified facts / unavailable access:
- Recommended bounded next action:
- Authorization required before that action:
- Existing versus fresh session choice, and why:

Success means a fresh session can explain the goal, decisions, verified state and
next action without the original conversation. Merely reading a handoff is not
proof that the work or a worker has resumed.
